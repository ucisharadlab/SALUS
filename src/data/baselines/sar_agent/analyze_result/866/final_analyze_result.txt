If the intention is to look for an exact 1:27 lap (which would reveal that none exists and thus return an empty set):

```
SELECT d.forename,
       d.surname,
       d.url
FROM lapTimes AS l
JOIN drivers AS d ON d.driverId = l.driverId
WHERE l.raceId = 161
  AND l.time IN ('1:27', '1:27.0', '1:27.00', '1:27.000');
```
