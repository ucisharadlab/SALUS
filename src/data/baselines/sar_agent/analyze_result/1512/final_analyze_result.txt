The annotated query groups by CustomerID for 2012-08-25 but orders by SUM(Price), ignoring Amount. Executing the correct aggregation shows customer 7938 paid 554 529.36, whereas the annotated query would return customer 19182 (only 6 287.70 by SUM(Price)). Revised: 
SELECT `CustomerID`
FROM `transactions_1k`
WHERE `Date` = '2012-08-25'
GROUP BY `CustomerID`
ORDER BY SUM(`Amount` * `Price`) DESC
LIMIT 1;
