In the results table the finishing order is stored in the numeric column positionOrder (or position). Revised: SELECT d.`driverRef`
FROM `races` r
JOIN `results` res ON res.`raceId` = r.`raceId`
JOIN `drivers` d ON d.`driverId` = res.`driverId`
WHERE r.`name` = 'Canadian Grand Prix'
  AND r.`year` = 2007
  AND res.`positionOrder` = 1;
